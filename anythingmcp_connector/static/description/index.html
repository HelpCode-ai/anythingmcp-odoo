Use Odoo in Claude, ChatGPT and Copilot

Ask your AI assistant about invoices, sales orders, customers and products, and get answers from your live Odoo data. AnythingMCP connects Odoo to AI assistants over MCP (Model Context Protocol). This module sets it up from Odoo's Settings in three steps, without code.

What you can ask

  • "Which customer invoices are more than 30 days overdue? Draft a payment reminder for the largest."
  • "What did Keller & Sohn order this year, and what is still to be delivered?"
  • "Which products sold best last month, and how many do we have in stock?"
  • "Create a quotation for Atelier Nord with two units of product X."

The assistant reads and writes through your own Odoo user and API key, so it sees and changes only what that user may.

How it works

  1. Install the module and open Settings → General Settings → AI Assistants.
  2. Click Create an API key. Odoo asks for your password and shows the new key once: copy it. On Odoo 18 and later, choose the longest duration offered.
  3. Click Open AnythingMCP. Your Odoo address and database (and on Odoo 17 and 18 your user id) are already filled in. Paste the key and click Check and install. AnythingMCP checks the key against your Odoo before it saves anything.
  4. Add AnythingMCP to Claude, ChatGPT or Copilot as shown at the end of the setup, and start asking.

On Odoo 19 and later AnythingMCP uses Odoo's JSON-2 API; on Odoo 17 and 18 the JSON-RPC API.

What the module does, and what it does not

  • It adds the AI Assistants block to General Settings: your Odoo address, database name and user id, and the two buttons.
  • It sends nothing on its own and collects no usage data. Only when you click "Open AnythingMCP" does your browser open AnythingMCP with your Odoo address, database name and user id in the link, never the API key. What AnythingMCP stores is described in its privacy policy.
  • It adds no models and changes no data. Uninstalling it removes the block; an API key you created stays under your user's Account Security until you revoke it.

Requirements

  • An AnythingMCP account. AnythingMCP Cloud runs in Frankfurt (EU): 7-day trial, then from €19 per month. AnythingMCP is also open source and can be self-hosted; set the system parameter anythingmcp_connector.url to your instance's address.
  • Odoo 17, 18 or 19 (Community or Enterprise), self-hosted or on Odoo.sh. Your Odoo must be reachable over HTTPS from the internet for AnythingMCP Cloud.
  • On Odoo Online you cannot install third-party modules, but you do not need this one: follow the Odoo guide and enter the same three values by hand.
